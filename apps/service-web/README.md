# service-web 

> darun.io web service

모바일에서도 로그인과 검색에 접근할 수 있습니다. 비교는 두 서비스까지 선택하며, 세 번째 선택은 기존 항목을 바꾸지 않고 안내합니다. 투표가 완료된 버튼은 중복 제출을 막으며 취소 기능이 있는 것처럼 표시하지 않습니다. 영어 번역이 없는 콘텐츠는 원문 표시임을 안내합니다.

검색 결과가 없을 때만 대체 탐색 데이터를 조회합니다. 제품별 입력과 요청 결과는 제품 전환 시 분리하며, 비교 목록 저장 실패는 사용자에게 알립니다. 클라이언트 탐색과 브라우저 뒤로·앞으로 이동에서도 검색어에 맞는 문서 제목을 유지합니다.
