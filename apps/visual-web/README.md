# 다른 Visual

실제 서비스의 화면·플로우·앱을 탐색하는 Next.js 프론트엔드입니다.

- 메인은 소개 영역 없이 검색·분류와 앱별 화면 묶음을 표시합니다. 각 앱에서 최신 공개 스크린샷을 최대 3장 미리 보고, 앱 이름이나 화면 수를 눌러 전체 화면으로 이동할 수 있습니다. 데스크톱은 2열, 모바일은 1열이며 저장 버튼은 이미지를 가리지 않도록 아래에 표시합니다.
- `/apps`는 스크린샷이 있는 앱을 화면 미리보기·앱 이름·화면 수로 보여주며 이름·slug 검색을 지원합니다. 스크린샷이 없는 앱의 상세 URL은 유지합니다.
- 화면 검색은 플랫폼·화면 유형·UI 요소·서비스 필터를 지원합니다. 조건 변경 시 입력한 검색어와 다른 조건을 유지하고, 서비스 필터의 ×는 서비스만 해제합니다. 초기화는 모든 조건을 제거합니다.
- 메인 화면 이미지는 원본 비율로 표시합니다. 분류 필터는 API에 저장된 값을 사용하며, 이 프론트엔드 변경은 프로덕션 분류 데이터를 수정하지 않습니다.
- 앱 상세는 스크린샷과 플로우를 먼저 표시하고 설명은 접힌 `앱 정보`에서 제공합니다. 설명 HTML은 기존 정제 경계를 유지해 스크립트·이벤트 핸들러·위험한 URL·인라인 CSS를 제거합니다.
- 플로우 검색도 서비스 필터만 해제하거나 검색어·플랫폼·유형·서비스 조건을 모두 초기화할 수 있습니다.
- 플로우 상세는 썸네일과 좌우 방향키로 단계를 이동하며, `?step=2`처럼 특정 단계를 공유할 수 있습니다. 단계 이동은 History API로 URL만 갱신해 확대창과 스크롤 위치를 유지합니다. 다른 쿼리 조건은 보존하고 첫 단계의 `step`은 생략합니다.
- 상세 화면에서 링크를 복사하고 스크린샷을 확대할 수 있습니다. 플로우 확대창에서도 단계를 이동할 수 있으며, Escape로 닫으면 확대 버튼으로 포커스가 돌아옵니다.
- 탐색 목록에는 본문 검색창 하나만 표시하고, 상세·컬렉션에서는 헤더 검색을 제공합니다. `⌘K`/`Ctrl+K`는 현재 페이지의 검색창으로 이동합니다. 모바일 검색 제안은 입력창 아래에 펼쳐집니다. 계정 저장 목록은 푸터에서 접근하며, 상세의 `계정 저장`은 브라우저 컬렉션 저장과 구분됩니다.
- `/collections`에서 이름을 붙인 컬렉션을 만들고 화면·플로우·앱을 저장하거나 제거할 수 있습니다. 컬렉션은 현재 브라우저의 `localStorage`에만 저장되며 계정·기기 간 동기화되지 않습니다. 브라우저 데이터를 삭제하면 컬렉션도 삭제됩니다. 컬렉션 식별자는 `crypto.randomUUID`를 우선하고, 없으면 `crypto.getRandomValues`로 만들며, 안전한 난수를 쓸 수 없으면 만들지 않고 오류를 표시합니다.

메인과 앱 목록은 기존 스크린샷 API의 모든 커서 페이지를 읽어 앱별로 묶고 중복 화면을 제거합니다. 첫 페이지에 없는 앱도 포함하며, API에 앱별 집계 기능이 생기면 이 메타데이터 순회를 대체할 수 있습니다.

## 로컬 실행

`.env.sample`의 환경 변수와 GraphQL API가 필요합니다. 개발 서버는 `pnpm --filter visual-web dev`로 실행하며 기본 포트는 `3002`입니다.

## 검증

`pnpm --filter visual-web lint`, `pnpm --filter visual-web typecheck`, `pnpm --filter visual-web test`로 검사합니다. 컬렉션 회귀 테스트는 저장 실패·손상 데이터·안전하지 않은 링크·중복 항목·새로고침 후 복원을 검증합니다. 앱 설명 테스트는 실제 컴포넌트를 렌더링해 HTML·일반 텍스트·빈 값과 악성 스크립트·CSS 제거를 검증합니다.

AI 의미 검색·스크린샷 OCR·Figma 연동은 제공하지 않습니다. 화면과 플로우 검색은 기존 GraphQL API의 검색 범위를 따릅니다.
